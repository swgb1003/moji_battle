# ワールド文字カップの実装・検証

大会選択に「ワタナベチャレンジカップ」と「ワールド文字カップ」を追加。既存の8文字・Sサイズ限定大会を保持し、新大会は共通カスタマイズからMサイズ限定で参加します。

## 大会進行

48文字 → A〜Lの12組・各4文字の総当たり（72試合）→ 各組1・2位24文字＋3位上位8文字 → ベスト32 → ベスト16 → 準々決勝 → 準決勝 → 3位決定戦 → 決勝 → 表彰式 → 記念写真 → 大会結果。

勝利3点・引き分け1点。グループ内の同成績は勝点・KO勝ち数・タイムアップ勝ちの残りHP合計・HP差・文字IDで確定。3位比較はKO勝ち数、タイムアップ勝ちの残りHP合計を優先し、同成績なら勝点・HP差・グループ順。リーグは延長なし、決勝の引き分けは同じ構成・異なるseedで再試合します。決勝初戦では同じグループの相手を避けています。

文字・字体・握り・反転・必殺の構成を大会開始時に固定。各試合でHP・ゲージを初期化。自分の試合は他グループの計算完了を待たず開始でき、戦闘中の計算は別の物理シーンで進めます。表示中の試合の物理設定を保ち、未完了の計算は中断時に取り消して同じseedで再開します。

準決勝敗者は3位決定戦へ。決勝進出時はCOM同士の3位決定戦を観戦、または結果の計算を選べます。敗退後にも残りの大会結果を確認できます。

優勝時は3人が表彰台に登りトロフィーを掲げ、花火・「優勝」「おめでとう」・撮影フラッシュへ進みます。記念写真のPNG保存、演出スキップ、設定の動きを抑える指定に対応。

## 検証

- EditMode 137件に合格（順位、対戦表、再試合、保存復元、カスタマイズ分離を含む）。
- PlayMode回帰36件に合格（ワタナベ大会、お題、ドラフト、連戦、メニュー、音声、新大会）。
- 最新の新大会フロー5件に合格（裏の計算、中断・再開、両側の操作権を含む）。
- 最後の表示調整後、優勝フロー1件を再確認し合格。
- PNGダウンロード連携のJavaScript検証5項目に合格。
- 画面を1920×1080で撮影。880×450、1280×960でもボタンの画面内への収まりを検証。
- ソースのSHA-256記録：world-cup-source.json。

スクリーンショットはUnityの実装画面を撮影したものです。ブラウザ上での自動操作は行っていません。
