# 設定画面の実装・検証（2026-10-10）

和紙・墨・朱色のデザイン案に合わせ、モード選択・対戦中から開く設定画面を実装した。タイトル画面の設定ボタンは、その後の要望で削除した。

- 基本、音楽、表示・演出、データの4タブ。
- 全体／BGM／効果音音量を別々に変更し、再生中の音にも適用。
- ランダムまたは戦闘曲01～03を選択。試聴は他のBGMと重ねず、再操作・タブ切り替え・終了で停止。
- 初期観戦速度1／2／4倍、開始時の操作説明、ダメージ数値、画面の揺れ・点滅、メニューの動き。
- 必殺技の通常／簡易表示。簡易でも踏ん張りの受付時間を保持。
- 自動保存、再読込、設定だけの初期値復帰。
- カスタマイズ・登録必殺技・称号進行の個別初期化。確認後に実行し、対戦中は無効。
- 通常対戦は開いた時に停止し、閉じると元の状態を復元。オンライン対戦はホストの試合・フレーム同期を継続。
- 背後の画面や確認ダイアログ背後の操作をブロックし、称号通知は設定を閉じるまで待機。

## 検証

- EditMode: **23 / 23 成功**。`settings-edit.xml`。設定永続化・値の補正・初期化・独立した値コピー、既存の必殺技と称号。
- PlayMode: **64 / 64 成功**。`settings-play.xml`。設定フロー5件、戦闘UI6件、音声15件、関与15件、称号8件、メニュー4件、友人対戦6件、大会5件。
- **計87件成功、失敗0件**。
- 設定フローは実際のUIからタブ・音量・曲選択・試聴・保存・キャンセル・初期化を操作。試聴の音源とミュート、再読込した値、背後の操作可否を検証。
- 実戦では初期4倍・固定曲・説明OFF、停止状態の復元、簡易必殺の表示と停止時間を確認。
- ダメージ表示のON/OFFとKOフラッシュ抑制が表示だけに作用し、HPを変更しないことを確認。
- ローカルの対戦サーバーを使用し、オンラインの設定表示中もホストの時計と配信フレームが進むことを確認。検証後にサーバーを停止。
- テストで変更した設定・カスタマイズ・必殺技・称号の保存データは各テストの終了時に復元。

詳しい仕様は [GameSettings.md](../Assets/Documentation/GameSettings.md)。
