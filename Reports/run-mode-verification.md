# 勝ち抜き・育成モード

全5戦。各勝利後に12種類から3つの候補を出し、1つを選んで強化。HPを引き継ぎ、字体・サイズ・持ち方などは共通カスタマイズ画面で調整できます。最初に選んだ一文字は挑戦中固定です。

メニュー → 説明 → 共通カスタマイズ → 次戦準備 → VS → 戦闘 → 勝利結果 → 強化選択 → 次戦準備。第5戦はボス、終了時はクリアまたは敗北画面。引き分けはHPを引き継いで同じ相手と再戦します。

進行、HP、相手、強化候補、クリックによる選択を保存。再開で候補を引き直しません。戦闘中に離れた場合は、その戦闘を開始した時点に戻ります。通常対戦の構成は変更しません。

育成の称号4種を追加（五連の覇者、不屈の育て手、多才の育成、連戦の達人）。結果と保存データから一度だけ記録し、新しい称号の通知を優先します。
