# ワールド文字カップの画面デザイン

全18画面を画像生成ツール（built-in image_gen）で作成。ゲーム本体は未実装。

index.html：拡大・前後移動つき画像一覧。
images.json：採用画像。prompts.json：初回プロンプト。edit-prompts.json：修正プロンプト。

決勝まで進んだプレイヤーの例：優勝 火、準優勝 水、3位 雷、4位 龍。
数値・対戦文字は例示。実装は大会データから表示。

画面遷移：大会選択→ルール→共通カスタマイズ(M固定)→抽選→グループリーグ(3戦)→進出結果と3位比較→決勝トーナメント(32/16/8/4)→3位決定戦→決勝→表彰式→祝福→記念撮影→大会結果。
準決勝敗者同士が3位決定戦を行う。プレイヤーが敗者なら本人の試合、決勝進出時は観戦可能。

演出案：約0〜6秒で3人が表彰台へ移動して杯を掲げる。約6〜10秒で花火と祝福文字。約10〜14秒で記念撮影・フラッシュ・写真の静止。その後大会結果へ。スキップあり。

1. 大会選択 — 01_tournament_select.png
   通常大会とワールド文字カップを選び分ける。
2. 大会ルール — 02_guide_v2.png
   M限定・48文字・12グループ・32文字進出・3位決定戦を説明。
3. 共通カスタマイズ — 03_customize_v3.png
   既存の共通カスタマイズ画面。M固定、開始後は構成固定。
4. 組み合わせ抽選 — 04_group_draw.png
   A〜Lの12グループを抽選。自分のグループを強調。
5. グループリーグ — 05_group_board.png
   自分のグループの順位、全6試合、次の対戦を確認。
6. 対戦前 — 06_vs.png
   両者の文字と構成を確認して試合を開始。
7. 戦闘 — 07_battle_v2.png
   共通の戦闘画面に大会・グループ・試合数を表示。
8. 試合結果 — 08_match_result_v2.png
   KO・決着時間・残りHPを確認し、グループ表に戻る。
9. グループ最終結果 — 09_group_qualified.png
   グループ最終順位と決勝トーナメント進出を表示。
10. 3位比較 — 10_third_ranking_v2.png
   各グループ3位の12文字を比較。上位8文字が進出。
11. 決勝トーナメント表 — 11_knockout_board_v2.png
   32文字から始まるトーナメント。画像は上位8文字の拡大表示。
12. 3位決定戦 — 12_bronze_match.png
   準決勝敗者同士の対戦。プレイヤーが敗者なら自分の試合として進行。
13. 決勝戦 — 13_final.png
   3位確定後に決勝戦。勝者が優勝、敗者が準優勝。
14. 表彰式・トロフィー — 14_podium.png
   演出案・約0〜6秒：3人が表彰台へ移動し、トロフィーを掲げる。
15. 祝福・花火 — 15_congratulations.png
   演出案・約6〜10秒：花火が上がり「優勝」「おめでとう」を表示。
16. 記念撮影 — 16_photo_v2.png
   演出案・約10〜14秒：記念撮影のポーズ→フラッシュ→写真で静止。
17. 大会結果 — 17_tournament_result.png
   優勝時の最終順位と大会通算成績。記念写真を見直せる。
18. 敗退時の結果 — 18_eliminated_v2.png
   途中敗退時の成績。再挑戦または大会の続きを観戦。
