# ワタナベチャレンジカップ

タイトルのSTART → モード選択 → トーナメントモード → 大会準備 → 大会エントリー。
エントリー後に8人のトーナメント表が表示され、「1回戦へ進む」で最初の試合を始める。

## 大会ルール

- プレイヤー1人＋COM7人の8人制。1回戦・準決勝・決勝の3試合に勝つと優勝。
- 全選手の文字サイズはS。サイズ以外は通常バトルと同じカスタマイズ・補正・AI・戦闘ルールを使う。
- プレイヤーは大会前に文字、収録済みの字体、持ち方、握る場所、戦闘スタイル、反転を選べる。
- 大会開始時に全員の装備をコピーして固定。大会中は変更できない。
- COMの文字は同梱フォントが対応する漢字・かな・英数字・記号からランダム。
  字体は収録済みのものから選び、持ち方・握り位置・スタイル・反転もランダムにする。
- 各試合はHPと戦闘状態をリセットして開始する。
- 敗戦した時点で敗退。表に結果と最終的なCOM優勝者を表示する。
- 引き分けは勝利・敗戦に数えず、同じ相手・同じ装備で再試合する。
  再試合では新しい試合seedを使い、勝敗がつくまで繰り返す。

## トーナメント表

大会開始時とプレイヤーの各試合後に表示する。勝ち上がりの線と「勝ち／敗退」を表示し、
次の対戦相手の装備も確認できる。試合後は終了ゴングの余韻まで流してから表に戻る。
COM同士の試合は通常と同じ物理・AIで計算し、各ラウンドの結果を反映する。
集計は少しずつ処理するため、表の画面を表示したまま進む。COM集計では音・KOスローを再生しない。
無効にした棒人間表示は戦闘イベントに反応せず、技名や受け流しの文字を再表示しない。
初期状態で非表示の文字・背景板も含め、COM戦の描画を無効にする。
プレイヤーが敗退した場合は残りのCOM同士の試合も計算し、完成した表を表示する。

「もう一度挑戦する」で大会準備へ戻り、新しい大会にエントリーできる。
「モード選択へ」は現在の大会を終了する。途中状態の保存・再起動後の再開には対応していない。
通常バトルの保存済み設定は、大会の設定やCOM生成では書き換えない。

## 観戦操作

Spaceで一時停止、1・2・3で観戦速度、Cで当たり判定、DでAI表示。
大会中はR・Tの再戦とZ・X・N・Mの文字切り替えを無効にする。
BまたはEscは、試合中なら大会を棄権してモード選択へ戻り、試合終了後なら表へ戻る。
試合ごとに通常バトルと同じ開始ゴング・戦闘BGMを再生する。

## 実装

- `TournamentSession`：出場選手の固定装備、7試合の組み合わせ、勝ち上がり、敗退、引き分け再試合。
- `TournamentRuntimeStore`：大会準備の設定と、現在の大会をシーン間で保持。
- `TournamentOpponentGenerator`：大会seedで再現できるランダムCOM生成。
- `ModeSelectScreen` / `TournamentScreen`：モード分岐とトーナメント表。
- `MatchDirector.SimulateStep` / `SilentSimulation`：COM同士の試合を通常ルールで非表示実行。
- `GameFlow` / `BattleBootstrap` / `CustomizeScreen`：通常バトルと大会の画面遷移・装備制限。

追加シーンは`ModeSelect.unity`と`Tournament.unity`。Build Settings登録済み。
シーンを作り直す場合は **MojiBattle → Setup Tournament Scenes**。
