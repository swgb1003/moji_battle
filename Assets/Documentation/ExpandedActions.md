# 戦闘アクション8案の実装

完全オートの戦闘に、相手の技・距離・壁・字形に応じた行動を追加。
観戦操作の追加はなく、通常の対戦でAIが選択する。

| 行動 | 発動・動き | 隙と制約 |
|---|---|---|
| しゃがみ回避 → 斬り返し | 軽量・中量級が横薙ぎ・回転斬り・ぶん回しへ反応。0.38秒低い姿勢を取り、射程内なら短い構えから斬り上げ | 本体の部位Colliderと表示を実際に低くする。無敵なし。下段攻撃には選ばず、よろけ・転倒・KOで反撃を取り消す。専用間隔3秒 |
| フェイント → 攻め直し | ガード中、またはガードを好む相手に、0.28秒の上段予兆を見せる。相手が低く守ったら振り下ろし、高く守ったら突き | 予兆を相手AIも脅威として認識する。フェイント自体にダメージはなく、被弾で中断。カウンタースタイルは反撃の好機に限定。間隔4秒 |
| 鍔迫り合い → 押し返し／離脱 | 両者の有効攻撃中の武器接触で、武器質量比1.35以内・勢い比1.75以内なら最大0.5秒押し合う | 元の両攻撃を台帳で解決済みにし、同時に届いた本体接触より優先する。十分重い側は押し返し、それ以外は離脱。跳び斬りは対象外。片方が中断されたらもう片方も解除。間隔5秒 |
| 前蹴り → 武器攻撃 | 約0.9以内の密着で前蹴り。足先と相手の部位Colliderの距離で命中を判定し、小ダメージで離す | 武器のダメージ判定は停止。下段ガードで受けられ、蹴りを受け流して武器反撃はしない。空振りにも硬直あり。軽量・中量級は命中後、条件が合えば踏み込み斬りへ。間隔3秒 |
| 壁蹴り → 背後へ着地 | 背後の壁から1.2以内、相手から2.3以内に追い込まれた軽量・中量級が跳ぶ | 壁越え補正を使用。空中で相手に乗らないため跳び斬りと同じ衝突補助を使用するが、武器の重なり命中判定は継続。攻撃されると中断。着地まで次の攻撃を選ばない。間隔5秒 |
| 武器拾い → 払い斬り | 近くの落ちた武器を実際に拾い、相手が射程内なら低い位置から斬り上げ | 回収タイムアウトによる自動復帰では発動しない。相手KO・転倒中も発動しない。間隔4秒 |
| 起き上がりの選択 | 復帰モーション終了時、近くに相手がいれば起き上がり蹴り、遠くにいて背後に余地があれば後転 | 起き上がり蹴りは前蹴りと同じ足の判定・硬直・間隔。後転は位置移動のみで無敵なし。壁に背を付けた時は通常復帰 |
| 文字の角で引っ掛け → 引き崩し | Collider矩形の集合から画線間の凹み・穴を解析。ガード中の相手へ武器を差し出し、凹み付近の接触、または穴の中に入った相手の武器を検知して引く | 実際の武器Collider位置を使い、文字の意味に依存しない。直線の「一」には凹みがない。単なる本体接触ではダメージなし。相手武器が1.5倍より重いと自分が引っ張り負ける。台帳で1回に制限。間隔4秒 |

## 表示・音・調整

各行動の開始・成功を陣営色の技名で表示。蹴りは足を伸ばす専用表示、しゃがみは低い姿勢、後転は回転姿勢、フェイントは上段の予兆を使う。
音は既存の回避・ジャンプ・軽い振り・弾き・ガード崩し・武器回収素材を場面に対応させ、同じ開始音を二重再生しない。

`CombatBalance` の「追加アクション: 回避・崩し・復帰」で発動率・間隔・時間・距離を調整可能。
`expandedActions` でAIによる新アクションの選択をまとめて切り替えられる。
時間はすべて試合のシミュレーション時計、乱数は既存の陣営別PRNGを使用する。

中心処理は `FighterActions`。`FighterBrain` が状況判断、`Fighter` / `HitResolver` が状態遷移と命中、`StickmanView` が表示を担当する。
`ExpandedActionTests` に個別動作・被弾中断・多重命中防止・壁際復帰の検証を収録。
