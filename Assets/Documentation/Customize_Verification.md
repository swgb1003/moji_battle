# カスタマイズ機能①〜④ — 実装と確認結果

対象: 「文字武器オートバトル カスタマイズ機能①〜④ 実装仕様書」（持ち方・戦闘スタイル・握る位置・文字サイズ）。
計測値は `Reports/customize_check.md`（PlayMode `CustomizePlayModeTests` が出力）。画面は `Reports/Screenshots/20〜26_*.png`。

## 1. 既存コードの調査結果（仕様 25）

| 項目 | 既存の実装 |
|---|---|
| Unity | 6000.0.61f1、Built-in RP、2D Physics。試合ごとに専用の 2D 物理シーンを手動 Simulate |
| シーン | `Battle.unity` のみ（`BattleBootstrap` が試合を組み立てる。UI は TextMesh / IMGUI） |
| ファイター | プレハブ無し。`FighterFactory` が本体 Rigidbody2D（回転固定）・部位 Collider・武器 Rigidbody2D をコードで生成 |
| 文字の武器化 | ベイク済み `GlyphDefinition`（256×256 マスク・特徴量・最大 64 個の BoxCollider 矩形）→ `WeaponGeometry`（縮尺・握り点・重心） |
| 文字と手の接続 | 武器 Rigidbody2D を `HingeJoint2D` で肩へ 1 点接続。`WeaponMotor2D` が目標角へのトルク制御（PD・加速度上限・重力補償） |
| AI | `FighterBrain`（0.15 秒周期）。重量クラス（軽量/中量/重量）ごとの `ClassTendency` で攻撃・ガード・回避・離脱を決める |
| HP・ダメージ | `HitResolver`（1 ステップ蓄積→解決、ガード優先、1 スイング 1 回）・`DamageMath`・`MatchDirector`（KO・時間切れ・延長戦） |

### 流用 / 変更 / 新規

- **流用**: 字形・Collider 生成、ヒンジ＋トルク制御、HitResolver・ダメージ式・ノックバック、FighterBrain の判断構造、HP・KO・勝敗、HUD・演出
- **変更**（カスタマイズ無しの試合では挙動が変わらないよう、補正はすべて `FighterModifiers.Identity` で無効）
  - `FighterFactory`: 縮尺・握り点・武器質量をビルドから決める（表示 Sprite・Collider・重心・射程は同じ `WeaponGeometry` から作るので必ず一致）
  - `WeaponMotor2D`: 最大角加速度に「慣性比（扱いやすさ）」と持ち方の攻撃時トルクを掛ける
  - `Fighter`: 攻撃時間に攻撃速度を反映。カスタマイズ時は溜め・振り抜き・硬直を **武器の実際の角度** で進める（重い武器は物理的に遅い）
  - `HitResolver`: ガード安定性・ガード範囲・ノックバック耐性・質量を通じた威力
  - `FighterBrain`: 戦闘スタイルのフック呼び出し（スタイルごとの if 文は持たない）
  - `MatchDirector`: カスタマイズ武器の引っ掛かり（握りのずれ）解消
  - `BattleBootstrap` / HUD: ビルドで試合・再戦、リザルトのボタン、ビルド表示
- **新規**: `FighterBuildData`・`BuildRuntimeStore`・`CustomizeBalance`（ScriptableObject）・`FighterModifiers`・`WeaponSizeController`・`WeaponGripController`・`FighterCustomizer`・`BattleStyleStrategy` と 4 スタイル・`FighterPreviewController`・`CustomizeScreen`・`TitleScreen`・`GameFlow`・`UguiKit`、`Title.unity`・`Customize.unity`

## 2. 仕様との対応

| 仕様 | 実装 |
|---|---|
| 5 データモデル | `FighterBuildData`（字体は既存の `FontStyleId`）。既定 M / 片手 / 0.5 / 猛攻 |
| 6 持ち方 | `CustomizeBalance.oneHanded/twoHanded/reverse/horizontal` の倍率をそのまま採用。攻撃速度＝溜め・振り・硬直、攻撃時トルク＝溜め・振り中の最大トルク、ガード安定性＝ガード崩し閾値×・ガード時の押し込み÷、ノックバック耐性＝本体ヒットの衝撃÷、有効リーチ＝AI の射程、ガード範囲＝正面判定角、回避後攻撃速度＝回避後 1 秒以内の溜め÷。両手持ちの添え手は表示のみ（物理接続は握り 1 点）。逆手は字形を前腕に沿って後ろへ流す構え（ψ=175°）、横持ちは前へ水平（ψ=0°）で AI のガード重み +0.25 |
| 7 戦闘スタイル | `BattleStyleStrategy` ＋ `Aggressive/HitAndAway/Counter/DefensiveStrategy`。AI 重みの置き換えと、離脱・好機・待ち・連続ガード上限・構えのフック。H&A は攻撃後に必ず離脱（0.5〜1.2 秒、重量級ほど短い）、カウンターは相手の攻撃後 0.6 秒を最優先、鉄壁は連続ガード最大 2.5 秒・解除後 0.5 秒 |
| 8 握る位置 | 0〜1 を Clamp(0.08〜0.92) し、字形の長い方の軸に沿った位置の画線の太さ中央を握る（実際のヒンジ位置・Sprite の基点・Collider の相対位置が変わる）。数値補正は無く、慣性モーメント（leverArm）だけで扱いにくさが出る |
| 9 文字サイズ | S/M/L/XL の表どおり。最大辺（Sprite・Collider・握り点・射程）と質量を同時に更新。M の最大辺は 1.8（武器サイズ検証で 2.2→1.8 に変更） |
| 11 最終パラメータ | 武器質量 = 字形 × サイズ、攻撃速度・移動速度 = サイズ × 持ち方。スタイルは数値に掛けない。握る位置は物理配置のみ |
| 12 ダメージ | 既存の式を流用し、与ダメージに (質量倍率)^0.5 を掛ける（サイズは質量を通じてだけ威力に効く）。衝撃は既存どおり武器質量×相対速度 |
| 13 ノックバック | 既存（衝撃 ÷ 本体質量、上限あり）＋ノックバック耐性 |
| 14 AI 構成 | 既存の FighterBrain を AI 統括として残し、スタイルを Strategy に分離（全面書き換えはしない） |
| 16 シーン | Title → Customize → Battle。VS 確認は Customize 内、リザルトは Battle 内のオーバーレイ |
| 20 デバッグ | C: Collider・握り点（橙）・重心（青×）、D: AI 状態・スタイル・サイズ/持ち方・質量・leverArm・扱いやすさ・距離・射程。リリースビルドでは C の表示は出ない |
| 21 保存 | `BuildRuntimeStore`（シーン間保持＋PlayerPrefs の JSON）。リザルトの「同じ設定でもう一度」で再利用 |

## 4. 仕様との差分・判断

- **握る位置の軸**: 仕様は横軸（左端→右端）。縦長の字形（I など）は横軸だとほぼ動かないため「長い方の軸」に沿わせた（横長・正方形は仕様どおり左→右、縦長は下→上）。
- **姿勢の基準**: 既存の構え角は「握り→重心」基準。中央を握ると重心が握りに重なって向きが定まらないため、カスタマイズ時は「長軸に沿って握りから遠い側の端」を基準にした。
- **攻撃の段階**: カスタマイズ時は溜め・振り抜き・硬直を時間でなく武器の実際の角度で終える（予定時間の最大 3 倍まで待つ。押さえ込まれたら待たない）。仕様 8.4「まず慣性・トルクで差を出す」に沿うため。
- **重量クラス**: AI の連撃数・間隔は字形ではなく実際の武器の扱いにくさから決め直す（XL を端で持った「一」は重量級の動き）。
- **長い武器**: 振り下ろしの終わり・下段ガード・斬り上げの開始を地面の手前に制限（長い武器を地面に押し付けて握りが外れるのを防ぐ）。
- **ランダム要素**: 仕様 12 の RandomFactor（±10%）は入れていない（既存の決定的なダメージ式と seed 再現性を維持）。
- **文字入力**: 入力欄はあるが、使えるのはベイク済みの 9 文字（一 口 山 火 鬱 A I O X）。それ以外は理由を表示して受け付けない。字体はゴシックのみ（他は「未収録」で選択不可）。
- **相手の設定**: 仕様は 1 体分のカスタマイズを想定。P1/P2 の両方を同じ画面で編集できるようにした。

## 5. 未実装・注意点

- 4 スタイルを映像だけで判別できるかの目視確認、Phase 7 の体感（S が速い・XL が重い・端持ちが扱いにくい）の観戦確認は未実施。
- 中央持ちの「一」はリーチが短く（M で射程約 1.0）、大きな字形相手には懐に入れず不利。既定（0.5）のままだと弱く感じる可能性がある。
- XL・端持ち・両手の組み合わせは、カスタマイズ無しより握りのずれが起きやすい（最大 0.9% の時間）。引っ掛かりは自動で解消するが、見た目に一瞬伸びることがある。
- バランス（構成間の勝率）は未調整。端持ちの XL「一」は強め（口に 3〜4 勝/4）。
- 文字入力の任意文字（実行時ベイク）、字体の追加は P3。
