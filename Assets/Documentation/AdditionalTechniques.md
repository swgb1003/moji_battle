# 追加技（2026-10-07）

## 踏み込み斬り / DashSlash

短く構えてから前へ滑り込み、約0.07秒後に振り下ろす。
S〜Mの武器（カスタマイズなしでは軽量・中量級）が、射程の少し外〜端から選ぶ。
踏み込み開始時に **「踏込斬り！」** を表示し、`dash_step` → `dash_swing` の順に再生。
本体に命中した時は `dash_hit`。通常の振り音・命中音と二重に鳴らさない。
移動は本体と武器へ同じ速度変化を与え、近づいたら減速する。空振り後は硬直があり、連撃にはつながない。
技の再使用間隔は3秒。

## 受け流し反撃 / Riposte

ガード中に予兆へ反応し、約0.24秒の受け流し窓へ正面の武器攻撃が来た場合に成功する。
成功時はその攻撃を台帳で解決済みにし、本体ダメージを防いで相手の武器を弾き、短いよろけを与える。
**「受け流し！」** と `parry` を出し、約0.1秒後に短い構えから斬り返す。
反撃を振り始める瞬間は **「反撃！」** と `counter_swing`、命中時は `counter_hit`。

窓を外した場合や重量差が大きい場合は通常ガードとして解決する。
飛行中の投げ武器、素手、空中、KO後は受け流し反撃の対象外。
反撃待ちに被弾してよろけ・転倒した場合は反撃を中止する。
再使用間隔は4秒。カウンタースタイル、鉄壁スタイルは受け流しを狙いやすい。

## 全身ぶん回し / Whirl

L〜XLの武器（カスタマイズなしでは重量級）が近〜中距離で選ぶ。
足を広げて大きく引き、体・両腕・武器を縦軸方向へ一周させる。
武器の奥行き角に合わせてColliderの幅・表示の向き、手の接続位置、体と脚の向きを変える。
通常の回転斬りより大きく構え、遅く重い一撃になり、振り終わりは体が揺れる長い硬直がある。

回転開始時は **「ぶん回し！」** と `whirl_swing`、命中時は `whirl_hit`。
同じ回転で多重ダメージを与えない。再使用間隔は5秒。
壁際の安全補正と、被弾・ガード・武器衝突の判定も既存の処理を使う。

## 表示と音

技名は陣営色で約0.4秒表示。頭上に追従し、画面端・上部HUDに重ならないよう表示範囲を制限する。
受け流しから反撃への表示は、同じ文字表示を切り替える。一時停止中は表示時間も止める。
命中音は実際のHitEventで鳴らす。音の選択・揺らぎは戦闘用乱数を消費しない。
新しい効果音8個を生成し、既存30個と合わせて38個を収録。
`Reports/combat_audio_preview.html` で全素材を試聴可能。

調整値は `CombatBalance` の「追加技」欄。AIの選択は `AttackTechniques` / `FighterBrain`、
ガード成功判定は `HitResolver`、モーションは `Fighter` / `FighterMotor2D` / `StickmanView`。
