# 二刀流の個別握り・漢字の分離

カスタマイズで二刀流を選び、プレビュー下の「右手」「左手」を切り替えると、それぞれの武器をドラッグして握る場所を指定できる。「中央に戻す」は選択中の手だけを戻す。ドラッグ中は選択中の字形を固定し、離した時に設定する。

対応漢字を入力してS・Mサイズを選ぶと、文字欄の分離ボタンを押せる。持ち方は二刀流になる。対応は121字（左右92字・上下20字・囲み9字）。ゴシック・明朝・丸ゴシック・筆文字の4字体で元の字形を事前ベイクしている。「分離できる字 →」から構造別の一覧を開き、文字を選んで分離装備できる。一覧表示中はWebの文字入力を隠し、Esc／外側クリック／閉じるボタンで戻る。文字固定のモードやL・XLでは一覧から文字を変更できない。

左右の例は「明 → 日・月」「校 → 木・交」、上下は「思 → 田・心」「花 → 艹・化」、囲みは「国 → 囗・玉」「回 → 囗・口」。最初の部品を右手、次の部品を左手に持ち、交換もできる。構造と部品名は `Assets/Resources/Glyphs/SplitKanji.csv` が管理する。分離方向を推測して全漢字へ適用する処理はない。表にない漢字・単体の部首・かな・英数字などの分離は無効。門構えなど別種の囲みや三分割・重なりの構造は今回の対象外。

左右・上下は画線の薄い経路を構成表の境界付近で探す。上下は元の画像を回転して同じ処理を使い、結果を元へ戻す。囲みは内側の領域を枠との隙間へ合わせる。つながった画線への小さな切り込みは修復するが、細い部首全体を他方へ吸収しないよう、その広がりも調べる。分離後の微小な孤立片と、画線から離れた薄い画素は取り除く。「氵」など本来離れている点・画線は残す。画像と当たり判定は同じマスクから生成し、大きさの比率と二本合わせた元の重量を保つ。筆文字など部品同士が接する場所には切り口ができる。

「左右交換」は文字部品とその握り設定をまとめて交換する。通常の二刀流でも使えるが、ドラフトやお題などで主武器が固定されている時は交換できない。「分離を解除」で通常の二刀流に戻る。分離中は副武器の文字入力を隠す。装備文字と必殺技の所属は元の漢字を維持する。L・XLでは従来どおり二刀流を使わない。文字を変更すると分離設定を解除する。

保存データとルーム通信に左右の握り・分離・左右交換を保持する。旧保存データの共通握りは、左右それぞれに同じ位置を引き継ぐ。副武器は従来どおり主武器に追従する方式で、形状・握り・先端速度から副武器の命中を判定する。

文字合成メニューは未実装。保存・通信には従来の`splitMing`フィールドを互換用に使用する。構成表の部品はFirst/Secondで扱い、Left/Rightは既存呼び出し用の別名。通信プロトコルはv4で、分離方式の違う古いクライアントが同じ試合に参加することを防ぐ。

追加手順: 構成CSVに部品・方向・境界を登録 → `python Tools/sync_split_catalog.py` → Unityの`GlyphBaker.BakeSplitPrototype`で4字体をベイク → PlayModeと画像で検証 → サーバーとWebを公開。`python Tools/sync_split_catalog.py --check`で対応表の一致、`python Tools/review_split_glyphs.py`で構造別の画像一覧を確認できる。複雑な接触や異体字は個別に調整・検証してから表に加える。

検証: `SplitExpansionTests`、`IndependentDualGripTests`、`GripDragTests`、既存二刀流・カスタマイズ・友人対戦のフローテスト。サーバーは `node --test Server/server.test.mjs`、公開先の二人分の設定共有は `node Tools/verify_dual_grip_room.mjs <server-url> <report-path> [漢字]` で確認する。
