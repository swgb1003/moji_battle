# 戦闘アクションと演出の強化

2026-10-12。立体的な身体と文字武器を活かす6要素を通常のバトルに追加。

| 要素 | 動作 |
|---|---|
| 全身モーション | 重い武器ほど深く腰を落とし、身体をひねって振り抜く。前足の踏み出し、後足の接地、回復動作を追加。握りは実際の武器位置へ追従 |
| 部位別の被弾 | 頭はのけぞり、胴は折れ、腕は肩を引き、脚は膝を崩す。ガードは腰を落として衝撃を受ける。物理・当たり判定を描画から変更しない |
| 空中追撃 | 軽量・中量の打ち上げ → 跳躍 → 空中斬り → 叩き落とし。重量級は既存の地上からの一撃を維持 |
| 鍔迫り合い | 押し合う姿勢、腕の震え、接触点の火花と床の墨跡。重い側は押し返して盾当て、拮抗時は一方が離脱し他方が斬り返す |
| 紙と墨 | 通常攻撃の先端に筆跡、命中時に斬撃線／衝撃輪、着地時に墨飛沫、叩き落とし時に紙の裂け目。床に薄い痕跡を残す |
| フィニッシュ | KOスローの開始から約0.08秒後に0.09秒静止、約0.18秒後に決まり手別の筆線／衝撃輪／墨柱と速度線。静止中は結果への遷移を待つ |

## 連携の条件と調整

- `CombatBalance.aerialCombos` / `bindCounters` で各追加アクションを切り替える。
- 空中追撃は打ち上げ命中後0.1秒以上、相手が空中・射程内、自分が攻撃中で武器を保持し、必殺技の連鎖中でない場合に開始。
- 再使用7秒、連携の上限1.1秒。被弾・転倒・着地・武器離脱・KO・試合終了で中断。新しい攻撃の開始でも古い追撃状態を解除する。
- 跳躍は既存の跳び斬りと同じく速度を放物線に沿わせ、武器の反作用で身体が上へ飛び過ぎるのを抑える。瞬間移動はしない。
- 空中斬りは通常の斬り上げの55%のダメージ。握りから相手の胸までの距離で届くか判定し、各段に個別の攻撃IDを発行して既存の命中台帳で重複を防ぐ。必中ではない。
- 鍔迫り合いは既存の質量・勢い条件、0.5秒の決着、5秒の再使用間隔を維持。反撃は実際の攻撃なので空振り・ガード・被弾がある。

## 演出と同期

- 追加の筆跡・衝撃波は最大64個を再利用。床の痕跡は最大24組で、古い痕跡から消す。通常の飛沫は最大180個。
- 演出軽減設定で追加の筆跡・痕跡・KO静止とフラッシュを抑制。設定を切り替えた時は表示中の追加エフェクトも消す。
- 大会の非表示シミュレーションは墨演出を生成しない。演出の乱数を戦闘AIの乱数へ混ぜない。
- 友人対戦はホストで追加アクションを計算。攻撃時間・攻撃ID・空中連携状態を姿勢フレームに追加し、既存のモーション／命中／KOイベントでゲストの演出を再現。
- KO種別は直前の命中／環境ダメージから判定。同時KOには専用の交差筆線と衝撃輪を使用。

実装: `CombatPose`、`StickmanView`、`FighterActions`、`CombatInkEffects`、`CombatVfxDirector`、`MatchDirector`、`FriendBattleFrame`。
検証: `CombatSpectacleTests` と既存の連携・拡張アクション・身体描画・効果音・友人対戦テスト。
