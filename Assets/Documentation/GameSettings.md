# 設定画面

モード選択メニュー・戦闘画面の「⚙ 設定」から開く。和紙、墨、朱色の既存UIを使い、1920×1080のセーフエリア内に配置する。

| タブ | 項目 |
| --- | --- |
| 基本 | 全体音量、BGM音量、効果音音量、戦闘BGM、試聴、初期観戦速度、開始時の操作説明、ダメージ数値、画面の揺れ・点滅、必殺技の演出 |
| 音楽 | ランダム／戦闘曲01～03の選択と試聴 |
| 表示・演出 | ダメージ数値、画面の揺れ・点滅、必殺技の演出、メニューの動き |
| データ | カスタマイズ、登録した必殺技、称号の進行をそれぞれ初期化 |

- 変更は `MojiBattle.Settings.v1` に自動保存する。メニューの動きは既存の `MenuReducedMotion` とF6操作に対応する。
- 初期値は全体80%、BGM60%、効果音90%、戦闘BGMランダム、観戦速度1倍。操作説明とダメージ数値は表示し、演出は通常。
- 音量は既存の各音源のバランスに掛ける。0%で消音し、再生中の音源にも変更を反映する。
- 試聴中は現在のBGMをミュートする。同じ曲の試聴ボタンをもう一度押す、タブを変える、設定を閉じると停止する。
- 戦闘BGMと初期観戦速度は次の対戦から適用する。大会決勝は専用BGM、オンライン対戦の速度は1倍のまま。
- ダメージ数値を非表示にしても、技名・ガード・ダウン等の表示は残す。HPやダメージ計算は変えない。
- 「控えめ」はカメラの揺れ・ズームパンチ、KO／必殺技の強い画面フラッシュや集中線を抑える。
- 必殺技は「通常／簡易」を選択する。簡易は小さな技名表示で、踏ん張りの受付時間とネットワークの停止時間は通常と同じ1.45秒を保つ。
- 通常対戦中に設定を開くと一時停止し、閉じると開く前の停止状態と観戦速度に戻る。オンライン対戦は進行を止めず、画面内にその旨を表示する。
- 背後のUIはマウスとキーボード両方の操作をブロックする。Escは確認画面、曲選択、設定画面の順に閉じる。
- 設定中の称号通知は表示時間を保って待機する。
- 初期化は確認画面で実行した場合のみ行う。「初期設定に戻す」は音・表示の設定だけを戻す。対戦中はデータ初期化を無効にする。
- 必殺技の初期化では保存ライブラリと装備中の自作技を消し、文字別の初期必殺技に戻す。称号初期化では旧データの移行による再獲得を防ぐ。

実装: `GameSettings.cs`、`SettingsScreen.cs`。画面遷移を使わないオーバーレイなので、メニュー・トーナメント・対戦ルームの状態を維持する。
