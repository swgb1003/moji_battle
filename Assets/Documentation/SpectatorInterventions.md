# 観戦者の関与（必殺技・声援）

戦闘は従来どおり AI が自動で行う。観戦者は 2 つの操作だけで勝負どころに関与できる。
ジャストガードは難しすぎたため廃止した（2026-10-08）。

| 操作 | キー / 画面 | 効果 |
|---|---|---|
| 必殺技 | **K**、ボタン（ゲージ満タン時） | カスタマイズで装備した必殺技を出す（下記）。**必ず当たる**。出せる状態（地上で攻撃・ひるみの最中でない）になるまで最大 5 秒待ち、出せなければ「届かず」と出て、ゲージは残る。 |
| 声援 | **L**、ボタン | 3 秒間、溜め ×0.85、与ダメージ ×1.1、相手の予兆への反応と受け流しの確率 +25%。次に使えるまで 10 秒。押すと掛け声（いけーっ！ など 4 種）と歓声が鳴り、効果の途中でもう一声かかる。 |
| 踏ん張り | 相手の必殺技の最中（カットインで止まっている間を含む）に **L**・ボタン | その必殺技で受けるダメージ ×0.7。再使用待ちでも押せる。声援の効果中に必殺技を受けた時は自動で踏ん張る。COM は 50% で踏ん張る。カットイン中は受ける側の画面に「L / 声援ボタンで踏ん張れ！」と出る。 |

- 必殺ゲージ: 毎秒 1/50、与ダメージ（相手の最大 HP 比）×0.6、被ダメージ（自分の最大 HP 比）×0.8、声援 +0.04。必殺の当たりではゲージは増えない。
- 一時停止中は押せない。
- 調整値は `CombatBalance.intervention`（`Resources/Balance/CombatBalance.asset`）。

## 必殺技の発動と必中

1. 発動: 試合の時間が 1.45 秒止まり、画面全体にカットイン（技の色の帯・武器の一文字・技名・読み・掛け声）が「シャキーン」という音とともに出る。止まっている間はヒットストップも進めない（`TimeController.TriggerFreeze`）。
2. 瞬歩: 各段の技を出す時、相手が間合いの外なら一瞬で相手の手前へ移る（壁際なら回り込む）。残像と速度線を引く。
3. 捕縛: 技の間、相手はひるみ続けて動けない（ガード・回避・受け流し・反撃なし）。倒れている・宙に浮いている間はそのまま。
4. 上限: 1 回の必殺技で与えるダメージの合計は、相手の最大 HP の 30% まで（段数に関係なく、`specialMaxShare`）。
5. 必中: 一段が体に当たらないまま振り抜くと（飛び道具・蹴りは技が終わった時）、その段の当たりを胴への一撃として確定させる（`HitResolver.ForceSpecialHit`）。打ち上げの段は確定でも叩き落としへつながる。
6. 演出: 技の間は背景が技の色に沈み、武器が光って残像と属性の粒を残し、足元に光の輪が出る。当たりごとに衝撃波・放射状の斬撃線・属性の大きな文字・画面のフラッシュ・重い炸裂音・ヒットストップ・揺れ・寄り。最後の段（または KO）はさらに大きく、長めに止めて「必殺」と出す。

## 必殺技（AI が技名から設計）

カスタマイズ画面の「必殺技」から作る。

1. 技名を付ける。選んだ一文字を必ず入れ、7 文字以内（サロゲートペアも 1 文字）。
2. 「AI で技をつくる」で、ルームサーバー経由で Claude（`claude-opus-5-5`）が名前を読み、動き・属性・色・演出の形・掛け声・説明を決める。
3. 一文字につき 3 つまで登録できる（端末に保存）。1 つを装備するとバトルの必殺ボタンで出る。未装備なら標準の技（L・XL は「大旋風」＝全身ぶん回し、それ以外は「一閃」＝踏み込み斬り）。

AI が決めるのは既存の部品の組み合わせだけで、物理と当たり判定はゲーム側が持つ。

| 項目 | 内容 |
|---|---|
| 動き | 1〜4 個の技を順に出す。振り下ろし・斬り上げ・突き・横薙ぎ・足払い・盾当て・打ち上げ（当たれば叩き落としへ連携）・回転斬り・跳び斬り・踏み込み斬り・全身ぶん回し・衝撃波・一画飛ばし・前蹴り |
| 威力 / 速さ / 伸び | 各 1〜5、合計 9 まで（サーバーとゲームの両方で丸める）。与ダメージ倍率 =（1.25 + 0.15×威力）÷ √技の数、溜め ×（1.05 − 0.08×速さ）、出せる距離 +6%×伸び・離れた相手へ 0.35×伸び m/s 踏み込む |
| 属性 | 墨・炎・雷・氷・風・水・土・光・闇・花・毒。技の間は武器が技の色に光り、属性ごとの粒（炎は昇る、雷は走る…）をこぼす |
| 演出の形 | 飛沫・輪・柱・斬撃・渦・雨。発動と当たりで出す |

- 連携: 一つの技が終わるたびに次の技を出す（離れていれば瞬歩で詰める）。自分が崩された・倒れた時は終わる。
- その武器で出せない技は近い技に置き換える（小さい字形の衝撃波 → 一画飛ばし、大きい字形の一画飛ばし → 衝撃波、全身ぶん回し → 回転斬り、重い字形の跳び斬り → 振り下ろし など）。必殺の飛び道具は通常の再使用間隔を待たない。
- 告知の帯は技の色で、技名と掛け声を出す。

### サーバーと費用

- `POST /specials`（`Server/specials.mjs`）。`ANTHROPIC_API_KEY` が無いサーバーでは「準備中」と返し、ゲームは標準の技で遊べる。
- 生成は 1 回ごとに Claude API の料金がかかる。接続元ごとに 1 時間 15 回、サーバー全体で 1 日 500 回（`SPECIAL_DAILY_LIMIT`）まで。同じ文字・技名は記憶した結果を返す（再起動で消える）。
- 公開に向かない技名（実在の人物・集団への中傷・差別・性的な内容）は AI が断る。格闘ゲームなので物騒な言葉は通す。
- ローカルの確認は `SPECIAL_FAKE=1 node server.mjs`（キーワードで決める代用。AI と料金を使わない）。公開サーバーでは使わない。

## 誰が操作するか

| モード | 左（P1） | 右（P2） |
|---|---|---|
| バトルモード | 観戦者 | COM |
| トーナメント | 観戦者（自分） | COM |
| 友人対戦 | 各端末の自分の陣営 | 相手の端末 |

COM はゲージ満タンから 0.4〜2.5 秒で必殺を出し、HP が 6 割を切ると時々声援する。COM の装備に必殺技が無ければ標準の技を使う。
`BattleBootstrap.interventions` を切ると、従来の完全オート観戦に戻る。
`MatchContext.Interventions` が無い試合（テストの試合・トーナメントの COM 同士の試合）は従来の計算のまま変わらない。

## 友人対戦

物理と勝敗はホストだけが計算する（従来どおり）。装備した必殺技は装備と一緒に部屋へ送られ、サーバーが同じ規則で丸める（AI を通さずに強い値を送っても合計 9 まで）。
ゲストの操作はルームサーバーの `POST /rooms/:code/input`（`special` / `cheer`）に送られ、ホストが部屋の情報を読むたびに試合へ反映する。
ゲージ・声援・必殺技の最中かどうかは試合の状態と一緒にゲストへ届き、ゲストも同じ演出を描く。
通信バージョンは `moji-fighter-x-rooms-v7`。旧版のゲーム・サーバーとはつながらない。

- `Scripts/Customize/SpecialMoveData.cs`: 技のデータ・技名の規則・丸め・登録（PlayerPrefs）
- `Scripts/UI/Customize/SpecialMovePanel.cs`: 必殺技の画面、`Scripts/Online/SpecialMoveClient.cs`: 生成の通信
- `Scripts/Combat/BattleIntervention.cs`: ゲージ・COM の操作・必殺技の連携（`SpecialMovePlan`）
- `Scripts/UI/InterventionHud.cs`: 操作パネル・ゲージ・告知、`Scripts/UI/SpecialCutIn.cs`: 発動のカットイン、`Scripts/UI/SpecialMoveVfx.cs`: 必殺技の演出
- 効果音 `Resources/Audio/Combat/special_cutin.wav`・`special_impact.wav`（numpy で合成）、声援の掛け声 `cheer_01〜04.wav`（Windows の音声合成 Haruka・Ichiro の声を重ね、歓声と反響を合成）
- `HitResolver`: 必殺のガード崩し、与ダメージ倍率（飛び道具は発射時の攻撃 ID で判定）
