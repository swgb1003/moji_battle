# 文字合成

モード選択の「文字合成」、またはカスタマイズ画面の「文字合成・保存一覧」から開く。

1. 分離対応121漢字（左右92字・上下20字・囲み9字）の両部品を素材にできる。素材の構造で絞り込み、「左 / 上 / 外」「右 / 下 / 内」で取り出す部品を選ぶ。合成先のどちらの枠にも、どちらの部品でも選べる。
2. 合成の配置を「左右に並べる」「上下に並べる」「囲み・重ねる」から選び、各部品の横幅・高さ・左右位置・上下位置、部品間隔、4種類の字体を調整する。部品のドラッグ移動と四隅のサイズ変更にも対応する。囲み素材の外側を第1部品にした場合は、その枠の内側に第2部品を配置する。それ以外の素材では中央に重ねる。
3. 「完成を確認」で約3.8秒の誕生演出。部品の吸引、衝突、閃光、墨しぶき、金色の衝撃波、完成文字の拡大と誕生印を表示する。音量・演出軽減・メニューアニメ設定に連動する。
4. 12文字までの名前を付け、「保存のみ」または「保存して装備する」を選ぶ。空欄では部品名を名前にする。
5. 保存一覧で装備・編集・削除ができる。最大48文字。保存先はこの端末／ブラウザーのPlayerPrefs。アカウント間同期や別ブラウザーへの移行機能はない。

## 武器と対戦

- 合成字は元のUnicode文字へ置換して描画するのではなく、二つの実際のマスクから256pxの字形を生成する。
- 表示・当たり判定・能力値は同じ字形から生成する。部品の能力値を加算する方式ではない。
- S・Mサイズでは合成後も再分離二刀流が可能。両手の持ち手・入れ替え・反転に対応する。
- 一般の二刀流で合成武器と通常文字を入れ替えても、合成レシピはその武器と一緒に移る。
- 保存一覧を編集・削除しても、装備済みの武器はコピーとして保持する。
- 元の文字が固定されるお題・ドラフト・勝ち抜きの固定文字では、合成文字への変更ボタンを出さない。
- 合成文字の必殺技は7文字以内で自由に命名でき、元の字や合成字の名前を技名に含める必要はない。通常文字には従来どおり、その文字を含める条件がある。
- 合成内容ごとに必殺技を3つ登録できる。通常の「合」や他の合成文字とは別枠。文字名を変更しても同じ部品・配置なら技を維持する。字体、持ち方、反転の変更でも技を維持する。
- AIには合成文字の表示名、元の漢字と取り出した部品、配置を渡す。内部識別子「合」を名前の入力条件には使わない。
- 合成文字の標準必殺技には「創字」の名を使い、戦闘中も同じ表示にする。
- 友人対戦は通信v7。画像を送らず、部品・配置・字体・名前を共有し、同じマスクと当たり判定を再生成する。旧版との接続はバージョン確認で拒否する。

## データ

- `FusionData` がレシピ、`FusionLibrary` が保存一覧を管理する。新規レシピはバージョン2で `layout`、`leftUseSecond`、`rightUseFirst` を保存する。保存一覧のキーは変えず、以前のバージョン1レシピは従来の部品選択と配置計算で復元する。新しい素材・部品・配置を選んだときにバージョン2へ更新する。
- `FighterBuildData.fusionEnabled` と `offhandFusionEnabled` は必須の存在フラグ。Unityのinline JSONはnullクラスを既定値に変換するため、レシピフィールドのnull判定だけで有効化しない。
- 合成プレビューのキャッシュは48件に制限し、破棄する際は反転画像も解放する。
- 実在字に一致する組合せにはその字の内部識別子を使い、その他は内部識別子「合」を使う。武器形状と表示名は常にレシピを参照する。
- 保存一覧と装備はdeep copyし、他の編集や削除の影響を避ける。

確認画像は `Reports/UI/fusion_*.png`、形状比較は `Reports/Fusion/` に出力する。
