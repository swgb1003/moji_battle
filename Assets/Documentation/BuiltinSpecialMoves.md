# 文字ごとの初期必殺技

自作必殺技を装備していない時は `BuiltinSpecialMoves.For(character)` が初期技を選ぶ。既存の「一閃」に加えて30種類の連携を用意した。サイズではなく文字の意味で選び、武器で実行できない動きだけ `BattleIntervention.Usable` で置き換える。

意味の近い文字（例：火・炎・燃・灼・熱）には同じ系統を割り当てる。その他の漢字、かな、英数字、記号、補助漢字も文字のUTF-16値から固定の系統を選ぶ。技名には選択文字を必ず含める。割り当ては端末、再起動、友人対戦のホスト・ゲストで共通。

初期技は登録枠3個を消費しない。自作技を装備するとそちらを優先し、標準に戻すと現在の文字の初期技に戻る。威力・速さ・伸びの合計は9以下、動きは1〜4段で自作技と同じダメージ制限を使う。属性11種、演出6種の既存描画を初期技にも適用する。

## 声援と踏ん張り

COMはHPが満タンでも声援を使用し、声援ゲージの回復後に再度使用する。必殺技の入力待ちと声援の判断タイマーは独立。

通常声援と必殺技への踏ん張りは、ともに声援ゲージが満タンの時だけ使用できる。使用するとゲージを消費し、10秒で再使用可能になる（調整値 `cheerCooldown`）。踏ん張りも通常声援として記録・同期する。声援の効果中に必殺技を受けた時は、既にゲージを消費した声援の効果で自動的に踏ん張る。

COM・ローカル・友人対戦の相手は同じ受付処理を使い、再使用待ち中の無料の踏ん張りは廃止。待機中はボタンを無効にし、必殺カットインにも回復待ちを表示する。
